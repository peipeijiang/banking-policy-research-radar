<summary><strong>中文摘要</strong></summary>

我们提出了一种在线多元分布预测模型，其中我们将藤copula（vine copula）的参数以协变量为条件。一种在线算法仅使用最近的观测值来序贯更新参数。现有方法在每次更新步骤中都需要使用所有可用数据进行完整的批量重新估计，这使得它们在大规模预测应用中计算缓慢，并且不太适合依赖结构随时间变化的情形。模拟结果表明，该在线方法达到了与批量估计器相当的预测性能，同时大幅减少了计算时间。我们将该方法应用于英国五个地区电力净需求的预测，并表明：(i) 条件藤copula模型优于无条件高斯和藤copula基准模型；(ii) 当批量重新估计不可用时，在线估计提高了预测精度。该算法在Python包ondil中实现。

<summary><strong>英文摘要</strong></summary>

We propose an online multivariate distributional forecasting model in which we condition the parameters of a vine copula on covariates. An online algorithm updates the parameters sequentially using only the most recent observations. Existing approaches require full batch re-estimation using all available data at each update step, which makes them computationally slow in large-scale forecasting applications and less suitable for settings in which dependence structures change over time. Simulation results show that the online procedure achieves forecasting performance comparable to that of the batch estimator, while reducing computation time substantially. We illustrate the method in a forecasting application to electricity net-demand across five regions of Great Britain and show that (i) the conditional vine copula model outperforms unconditional Gaussian and vine copula benchmarks and (ii) that online estimation improves forecast accuracy when batch re-estimation is not available. The algorithm is implemented in the Python package ondil.
