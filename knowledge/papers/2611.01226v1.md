# Learning about Markets from Models: Evidence from an AI Hiring Platform

[查看原文](http://arxiv.org/abs/2611.01226v1)

<summary><strong>中文摘要</strong></summary>

机器学习模型越来越多地不仅用于提供信息，还用于做出决策。有时平台通过跨情境汇集数据来提升模型的决策能力，从而创造价值——但当最优决策因情境而异时，数据汇集可能并不会提高准确性。我们认为，即使平台在不同情境下存储截然不同的模型，仍然能够捕获一种模型比较外部性。这些模型共同反映了决策者在当前均衡中对相同数据的不同反应方式。政策制定者可以利用这种差异性来确定干预措施的优先次序；企业可以了解自身与竞争对手已经形成的差异，从而聚焦未来投资。我们的证据来自一个AI招聘平台，该平台服务于低技能劳动者的大型雇主。平台使用标准化心理测量评估来创建企业特定模型，估计每份申请在该企业的留任可能性。每个企业的模型对自身具有高度预测力，但对其他企业则并不优于随机猜测。我们利用这些模型构建了一个企业—申请矩阵：每个企业对每份申请进行评分，而不仅是其收到的申请。一份申请若提交至不同企业，其留任可能性的提升因特征而异，具有高度异质性。此外，这些增益源于两种不同的机制。最后，即使在这一低技能市场中，企业对特征的重视程度也各不相同：对于重要特征在边际上是提高还是降低留任率，企业之间存在分歧。这些洞见只有在平台能够同时获取完整申请池和每个企业特定模型时才成为可能。我们阐述了这些洞见对企业、政策制定者和平台的价值。

<summary><strong>英文摘要</strong></summary>

Machine learning models are increasingly used to not only inform, but make decisions. Sometimes platforms add value by pooling data across contexts to improve models' decision making---but when the optimal decision differs by context, pooling may not increase accuracy. We argue that a platform storing starkly distinct models across contexts nevertheless captures a model comparison externality. Together, these models reflect how decision makers respond differently to the same data in the current equilibrium. Policymakers can use this differentiation to prioritize interventions; firms can learn how they are already differentiated from competitors to focus future investments. Our evidence comes from an AI hiring platform used by large employers of low-skill workers. The platform uses a standardized psychometric assessment to create firm-specific models estimating each application's retention likelihood at that firm. Each firm's model is highly predictive for itself but no better than chance at other firms. We use these models to create a firm-application matrix: each firm scores each application, not only the ones it receives. An application's improved retention likelihood if submitted to a different firm is highly heterogeneous based on traits. Further, these gains are due to two distinct mechanisms. Finally, firms value traits differently even in this low skill market: they disagree about whether important traits improve or worsen retention at the margin. These insights are only possible when a platform can access both the full application pool and each firm-specific model. We explain the value of these insights to firms, policymakers, and platforms.
