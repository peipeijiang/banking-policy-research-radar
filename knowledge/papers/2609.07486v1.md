<summary><strong>中文摘要</strong></summary>

网络保险需要对最坏情况下的灾难性（cat）事件进行精确建模，但该领域缺乏用于估计上限损失的稳健定量方法。基于近期收集的30年间24起网络灾难事件数据集，本研究检验了网络经济损失是否遵循幂律分布。我们分析了“网络小猫”——即规模低于10亿美元的事件，与灾难事件（10亿美元以上）仅存在量级差异——这些数据通过大语言模型从网络保险索赔数据（2020—2024年）中提取。以受害者数量（按索赔年份加权）作为经济损失的代理指标，我们将小猫级事件与已知灾难事件相关联以估计损失。小猫级事件的分布与灾难事件数据集一致，且幂律在统计上具有合理性：事件规模每增加一个数量级，其发生概率下降5至7倍。据此外推，规模为2020—2024年间最大灾难事件100倍的事件预计约每206年发生一次，对应损失达1000至2500亿美元——这虽属灾难性，但相对于其他保险险种而言并非异常极端。

<summary><strong>英文摘要</strong></summary>

Cyber insurance requires accurate modeling of worst-case catastrophic (cat) events, but the field lacks robust quantitative approaches for estimating upper-bound losses. Building on a recent dataset of 24 cyber cat events over 30 years, this work tests whether cyber economic losses follow a power law distribution. We analyze "cyber kittens" - sub-1B USD events distinguished from cat events (1B+ USD) only by magnitude - extracted via LLM from cyber insurance claims data (2020-2024). Using victim count (weighted by claim year) as a proxy for economic loss, we link kitten-sized events to known cat events to estimate losses. The kitten distribution proved consistent with the cat dataset, and power laws were statistically plausible: each order-of-magnitude increase in event size corresponds to a 5-7x drop in probability. Extrapolating, an event 100x the largest 2020-2024 cat event is expected roughly every 206 years, translating to 100-250B USD in losses - catastrophic, but not extraordinary relative to other insurance lines.
