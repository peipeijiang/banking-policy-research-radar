# von Neumann-Morgenstern stable sets in job matching problems

[查看原文](http://arxiv.org/abs/2611.00708v1)

## 一句话结论

> 论文证明在多对一职位匹配模型中，当存在唯一有效匹配时，所有个体理性且有效的匹配结果构成一个vNM稳定集；若有效匹配不唯一则vNM稳定集可能不存在，并刻画了'丰富'vNM稳定集存在当且仅当有效匹配集本质唯一。

<summary><strong>中文摘要</strong></summary>

我们证明，在多对一工作匹配模型中，冯·诺依曼-摩根斯坦（von Neumann-Morgenstern, vNM）稳定集一般存在。与该模型中可能为空的核心不同，只要存在唯一有效匹配，vNM稳定集就存在：所有个体理性（individually rational, IR）且有效的结果所构成的集合形成一个vNM稳定集。如果一个经济具有多个有效匹配，则vNM稳定集可能不存在。如果要求vNM稳定集在某种意义上是丰富的，那么这种丰富vNM稳定集存在当且仅当有效匹配集本质上是唯一的，并且所有有效且IR的结果所构成的集合形成唯一的丰富vNM稳定集。

<details>
<summary><strong>英文摘要</strong></summary>

We show that a von Neumann-Morgenstern (vNM) stable set generically exists in the many-to-one job-matching model. Unlike the core, which can be empty in this model, a vNM stable set exists whenever there is a unique efficient matching: the set of all individually rational (IR) and efficient outcomes form a vNM stable set. If an economy has multiple efficient matchings, a vNM stable set may not exist. If the vNM stable sets are required to be rich in a certain sense, then such a rich vNM stable set exists if and only if the set of efficient matchings is essentially unique, and the set of all efficient and IR outcomes forms the unique rich vNM stable set.

</details>
