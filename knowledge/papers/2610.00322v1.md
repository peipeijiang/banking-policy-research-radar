# Task Architecture and Learning from Coarse Performance

[查看原文](http://arxiv.org/abs/2610.00322v1)

## 一句话结论

> 论文用Blackwell序比较组织在只能观察到项目层面成功/失败时的任务架构（捆绑、单一窄任务、分离项目），推导出捆绑占优的阈值、固定工作量下的阈值变化以及后验方差公式，并分析阶段审计对占优区域的影响。

<summary><strong>中文摘要</strong></summary>

组织通常只能从项目层面的成功或失败中了解能力，即使一个项目包含若干互补任务也是如此。我们通过Blackwell序比较任务架构。一位能力固定但未知的专家可以执行以下三种安排中的任务：将所有任务捆绑在一个项目中，在由外部技术完成的项目中执行一项任务，或者将相同数量的任务分散到不同项目中。在外部可靠性低于某一阈值时，捆绑优于单一狭窄任务分配；否则二者不可比较。保持专家工作量固定会严格降低这一阈值，但不会推翻结论：当外部技术足够不可靠时，捆绑仍然占优；只有当该技术完美时，独立项目才占优；在其他情况下，实验不可比较。我们推导了任意任务数量下的阈值，并表明随着任务范围扩大，固定工作量阈值会降至零。显式的后验方差公式衡量了粗聚合在特定决策中的成本。最后，在双任务情形下，偶尔的阶段层面审计会根据一条精确边界扩大捆绑占优区域。

</details>

<summary><strong>英文摘要</strong></summary>

Organizations often learn about competence only from project-level success or failure, even when a project contains several complementary tasks. We compare task architectures by the Blackwell order. An expert of unknown fixed competence can perform all tasks in one bundled project, one task in a project completed by an outside technology, or the same number of tasks across separate projects. Bundling dominates a single narrow assignment below an outside-reliability threshold and is otherwise incomparable with it. Holding the expert's workload fixed strictly lowers this threshold but does not overturn the result: bundling still dominates when the outside technology is sufficiently unreliable, separate projects dominate only when that technology is perfect, and the experiments are otherwise incomparable. We derive the thresholds for any number of tasks and show that the fixed-workload threshold decreases to zero as task scope grows. Explicit posterior-variance formulas measure the cost of coarse aggregation for particular decisions. Finally, in the two-task case, occasional stage-level audits expand the bundling-dominance region according to an exact frontier.

</details>
