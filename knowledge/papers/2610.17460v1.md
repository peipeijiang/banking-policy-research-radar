<summary><strong>中文摘要</strong></summary>

我们研究稳定婚姻问题的一个连续版本，其中每个代理具有可变的质量，需要与另一方配对。代理的质量可以解释为单个原子代理的可分割时间，或者解释为某一特定类型的无穷小代理的质量。我们关注的对象是质量向量与稳定匹配集合之间的映射。正如经典稳定婚姻模型中所见，稳定匹配的集合可能是多值的，因此该映射是一个对应关系。当且仅当稳定匹配唯一时，该对应关系才是连续的，这意味着质量的微小变化可能导致稳定匹配集合的不连续跳跃。

</details>

<details>
<summary><strong>英文摘要</strong></summary>

We study a continuum version of the stable marriage problem, in which each agent has a variable mass to be paired to the opposite side. An agent's mass is interpretable as the divisible time of a single atomistic agent, or as a mass of infinitesimal agents of a particular type. Our object of interest is the mapping between the vector of masses to the set of stable matches. As in the canonical stable marriage model, the set of stable matches can be multi-valued, so this mapping is a correspondence. This correspondence is continuous if and only if the stable match is unique, implying that small changes in the masses may cause discontinuous jumps in the set of stable matches.

</details>
