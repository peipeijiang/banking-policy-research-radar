<summary><strong>中文摘要</strong></summary>

当数据拒绝一个计量经济模型时，研究者必须决定放弃哪些识别假设。如果若干同样受偏好的修复方案都能恢复兼容性，那么修复本身是未知的，且在任意一个修复方案下进行的推断都可能排除其他修复方案所支持的结构值，即使该推断是精确的。我提出后放松投影（Post-Relaxation Projection, PR），它将一个联合置信事件贯穿于每一个可能为最小修复的方案之中。借助逐修复方案的原始界，PR 等于与置信带兼容的所有后放松目标的并集，因此不存在具有相同保证的更小的基于置信带的集合。我推导了关于学习修复的极限、最小修复对应的精确扰动半径、oracle 等价自适应，以及一个在零第一阶段下有效的简化形式版本。在关于制度与收入的跨国数据中，数据无法确定应当剔除哪一个历史工具变量，但每一个可容许的最小修复都意味着制度具有正效应。

<summary><strong>英文摘要</strong></summary>

When data reject an econometric model, the researcher must decide which identifying assumptions to give up. If several equally preferred repairs restore compatibility, the repair itself is unknown, and inference under any one of them can exclude structural values supported by the others, even when that inference is exact. I propose Post-Relaxation Projection (PR), which carries one simultaneous confidence event through every repair that may be minimal. With repair-by-repair primitive bounds, PR equals the union of all post-relaxation targets compatible with the band, so no smaller band-based set has the same guarantee. I derive limits on learning the repair, the exact perturbation radius of the minimal-repair correspondence, oracle-equivalent adaptation, and a reduced-form version valid at zero first stages. In cross-country data on institutions and income, the data do not settle which historical instrument should be dropped, yet every admissible minimum repair implies a positive effect of institutions.

</details>
