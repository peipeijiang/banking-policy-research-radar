<summary><strong>中文摘要</strong></summary>

我们将Reny（2022）在学校选择情境中引入的优先级中性匹配概念，扩展至室友问题。我们证明了三个主要结果。第一，在任意可行性约束下的受限室友问题中，阻断中性匹配总是存在（定理1）。第二，稳定匹配的集合包含于阻断中性匹配的集合，而后者又包含于帕累托最优匹配的集合（定理2）。第三，只要稳定匹配存在，阻断中性匹配的集合与稳定匹配的集合重合（定理3）。我们还表明，在弱偏好下存在性不成立，并将该概念扩展至双边学校选择问题。

<summary><strong>英文摘要</strong></summary>

We extend the concept of priority-neutral matching, introduced by Reny (2022) in the school choice context, to the roommate problem. We prove three main results. First, a blocking-neutral matching always exists in constrained roommate problems under arbitrary feasibility constraints (Theorem 1). Second, the set of stable matchings is contained in the set of blocking-neutral matchings, which in turn is contained in the set of Pareto-optimal matchings (Theorem 2). Third, whenever stable matchings exist, the set of blocking-neutral matchings coincides with the set of stable matchings (Theorem 3). We also show that existence fails under weak preferences and extend the concept to two-sided school choice.
