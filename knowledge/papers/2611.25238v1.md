<summary><strong>中文摘要</strong></summary>

Shapley值归因是经济学中解释机器学习预测的默认方法，但它对每个特征只报告一个单一数值，并且对于某个特征联盟——该联盟共同贡献超过其所获得的分配——能否对该分配提出异议，则一无所知。我们通过一个解释方差博弈的核心（core）、核仁（nucleolus）和谈判集（bargaining set）来研究特征归因，其中一组特征的价值等于这些特征所生成的模型预测的方差。对于每个特征，我们报告一个稳定性区间（其在核心上的份额范围，或当核心为空时在最小核心上的份额范围），以核仁作为 distinguished point，并提供一个证明该分配不存在正当异议的证书。三个结果支撑了这一方法。第一，对于线性模型，该博弈恰好是2-可加的，成对的Harsanyi红利为$2β_iβ_jσ_{ij}$，因此多重共线性正是产生联盟结构的原因。第二，在每一个2-可加博弈中，预核仁（prenucleolus）与Shapley值重合，（最小）核心关于它点对称，且核心非空当且仅当交互图的每一个割都具有非负权重。因此，Shapley值始终位于预谈判集（prebargaining set）中，稳定性仅通过区间宽度和三阶或更高阶交互来增加信息。第三，对于凸博弈，区间具有闭式形式，且任何分配都可以用一个最小割来认证。在一个特征价格模型中，通常的mean-SHAP解释会受到联盟{Ratings, ROM, Battery}的正当异议。在一个零售订单的梯度提升预测器中，精确博弈具有空核心和强高阶交互；核仁与Shapley值的偏离最多达0.19个方差份额，而稀疏三阶代理模型能够在成对代理模型无法恢复的地方恢复它。

<summary><strong>英文摘要</strong></summary>

Shapley-value attributions are the default way of explaining machine-learning predictions in economics, but they report a single number per feature and say nothing about whether a coalition of features that jointly accounts for more than it receives could contest that allocation. We study feature attribution through the core, the nucleolus and the bargaining set of an explained-variance game, in which the worth of a set of features is the variance of the model's predictions that those features generate. For every feature we report a stability band (its range of shares over the core, or over the least core when the core is empty), with the nucleolus as distinguished point and a certificate that the allocation admits no justified objection. Three results organise the approach. First, for linear models the game is exactly 2-additive, with pairwise Harsanyi dividends $2β_iβ_jσ_{ij}$, so multicollinearity is what creates coalitional structure. Second, in every 2-additive game the prenucleolus coincides with the Shapley value, the (least) core is point-symmetric around it, and the core is non-empty if and only if every cut of the interaction graph has non-negative weight. The Shapley value thus always lies in the prebargaining set, and stability adds information only through band widths and interactions of order three or more. Third, for convex games the bands have a closed form and any allocation can be certified with one minimum cut. In a hedonic price model, the usual mean-SHAP explanation admits a justified objection by the coalition {Ratings, ROM, Battery}. In a gradient-boosting forecaster of retail orders the exact game has an empty core and strong higher-order interactions; the nucleolus departs from the Shapley value by up to 0.19 variance shares, and sparse third-order surrogates recover it where pairwise ones cannot.
