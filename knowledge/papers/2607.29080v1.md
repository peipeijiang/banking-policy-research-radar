<summary><strong>中文摘要</strong></summary>

我们引入罗尔斯公平（Rawlsian equity）这一概念，作为在无特定对象权利的情况下，在多个主体间分配不可分割对象的一种公平性准则。罗尔斯公平要求，除非某主体获得了其更偏好的对象，否则不得将某一对象分配给比另一主体更看重该对象的主体。我们证明，在一个辅助市场中，对象优先级取决于主体的偏好报告，罗尔斯公平分配集合与该辅助市场中的稳定分配集合一致。主体提议的延迟接受算法可计算出该集合中主体最优的分配结果，但一般而言，不存在满足策略防护的罗尔斯公平规则。

</details>

<details>
<summary><strong>英文摘要</strong></summary>

We introduce Rawlsian equity, a notion of fairness for allocating indivisible objects among agents without object-specific entitlements. Rawlsian equity requires that an object not be assigned to an agent who ranks it more highly than another agent unless the latter receives a more preferred object. We show that the set of Rawlsian equitable allocations coincides with the set of stable allocations in an auxiliary market where object priorities depend on agents' preference reports. The agent-proposing deferred acceptance algorithm computes the agent-optimal element of this set, but no Rawlsian equitable rule is strategy-proof in general.
