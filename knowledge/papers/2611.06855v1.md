<summary><strong>中文摘要</strong></summary>

我们考虑当某些协变量是内生的、存在一个足以控制内生性的变量但该变量是潜在的、且研究者可以生成许多潜在控制变量的代理变量时的线性回归问题。例如，人们可以使用不同的AI/ML方法廉价但不完美地插补潜在控制变量，每种方法生成不同的代理变量。在这种情况下，研究者可以考虑几种选择：将所有代理变量或由代理变量计算得到的因子作为控制变量纳入模型、工具变量估计，以及一些非线性变体方法。我们使用一个透明的模型来推导每种方法所针对的隐式估计量（implicit estimand），确定这些估计量何时能够恢复感兴趣的参数，并提供一些实用建议。我们证明，在生成的控制变量集合足够丰富的情况下，研究者可以在不依赖验证数据的情况下一致地估计感兴趣的参数。

<details>
<summary><strong>英文摘要</strong></summary>

We consider linear regression when some covariates are endogenous, a variable sufficient to control for endogeneity exists but is latent, and the practitioner can generate many proxies for the latent control. For instance, one could cheaply but imperfectly impute the latent control using different AI/ML methods, each generating a different proxy. There are several options the practitioner might consider in this scenario: including all proxies or factors computed from the proxies as controls, instrumental variables estimation, and some nonlinear variants thereof. We use a transparent model to derive the implicit estimand each approach targets, determine when these estimands recover the parameter of interest, and provide some practical recommendations. We show that with a sufficiently rich set of generated controls, practitioners can consistently estimate the parameter of interest without relying on validation data.
