<summary><strong>中文摘要</strong></summary>

为多运营商出行市场设计平台，以协调其运营或基础设施来支撑这些市场，需要建立模型来理解这些运营商和出行者在共享网络中的行为。分配博弈（assignment games）可被证明是有用的，但要将其实用化，需要采用一个更为广义的聚合分配博弈框架，以支持识别与估计。我们将这一框架拓展至聚合网络分配博弈，提出基于路径的公式和基于PURC的公式及相应的求解算法。针对基于连边的公式，提出一个逆优化模型，并通过一个二次规划进行求解，该规划分解为买方模块和卖方模块，前者保留节点势并施加所有观测到的零流单元约束。该估计器最初在文献中针对无容量约束的路径选择问题提出，本文将其拓展至有容量的双边市场，其中配给价格（rationing prices）支撑在观测到的紧约束连边上，运营商供给规模按组估计。基于玩具网络的计算测试展示了这些模型的经济价值。一个大规模长岛铁路（Long Island Rail Road, LIRR）网络算例（897个节点、671个人口普查区、123个LIRR车站、8,320条有向连边）被校准至2026年票价、时刻表座位供给和国家公共交通数据库（National Transit Database）运营成本。在10%–50%的连边采样率下，误设定的逆模型对oracle连边流量的拟合R^2>=96%。留出连边误差从29%降至19%，与真实配给价格的相关性从49%升至75%，社会最优总剩余恢复误差在6%以内。无谓损失被高估10%–17%。消融实验表明，忽略非活跃单元会使留出误差增加一倍以上，且在30%–50%采样率下，定价楔子的相关性大约减半，而忽略配给价格则会使每一项指标恶化。

<summary><strong>英文摘要</strong></summary>

To design platforms for multi-operator mobility markets coordinating their operations or infrastructure to support them, models are needed to understand the behavior of these operators and travelers in a shared network. Assignment games can prove useful, but operationalizing them requires adopting a more generalized aggregate assignment game framework that allows for identification and estimation. We extend such a framework to aggregate network assignment games, proposing a path-based formulation and a PURC-based formulation along with solution algorithms. An inverse optimization model is proposed for the link-based formulation. It is solved by a quadratic program that separates into a buyer block, which retains the node potentials and imposes every observed zero-flow cell, and a seller block. This estimator, introduced in the literature for uncapacitated route choice, is extended here to a capacitated two-sided market, with rationing prices supported on observed binding links and operator supply scales estimated by group. Computational tests with a toy network demonstrate the economic value of these models. A large-scale Long Island Rail Road network example (897 nodes, 671 census tracts, 123 LIRR stations, 8,320 directed links) is calibrated to 2026 fares, timetabled seat supply and National Transit Database operating costs. With 10-50% of links sampled, the misspecified inverse model fits oracle link flows with R^2>=96%. Held-out link error falls from 29% to 19%, correlations with the true rationing prices rise from 49% to 75%, and social optimal gross surplus is recovered within 6%. Deadweight loss is overestimated by 10-17%. Ablation tests show that ignoring the inactive cells more than doubles the held-out error and, at 30-50% sampling, roughly halves the correlation of the pricing wedge, while ignoring the rationing prices degrades every metric.
