<summary><strong>中文摘要</strong></summary>

强化学习投资组合策略能够基于价格、协方差和先验头寸优化配置，但缺乏一种经过校准、可重放的机制，用于在执行前证明所提议的配置满足有界风险包络。监管机构日益期望自动化投资组合系统提供此类交易前审计追踪、可解释的风险限额以及人工监督机制。门控共形语义风险控制（Gated Conformal Semantic Risk Control）通过将追求收益的配置与文本条件下的下行风险验证相分离来填补这一空白。一个经过指令微调的语言模型将带时间戳的披露信息映射为模式验证的语义风险状态，覆盖宏观、流动性、盈利和行业渠道。这些状态诱导出相关的椭球因子冲击不确定性集合，其共形半径通过局部语义非一致性分桶上的滚动有限样本预测进行校准。随后，一个非对称二阶锥门控将每个原始PPO提议与经认证的最坏情况语义损失预算进行比对。该门控对合规提议保持不活跃，仅在超出该预算时进行干预。在九只流动性良好的美国Select Sector SPDR ETF上进行的前向滚动样本外测试中，原始PPO实现了12.7%的年化收益，同时产生4.05%的语义违规率。Gated-CSRC消除了所有观测到的样本外语义限额突破，同时保留了11.7%的年化收益。这100个基点的可审计安全溢价小于无条件硬投影所带来的收益损失，且精确McNemar检验在\(p < 10^{-15}\)水平上确认了合规性增益。Loughran-McDonald词典对照和时间打乱文本对照均无法复现该认证。

<summary><strong>英文摘要</strong></summary>

Reinforcement-learning portfolio policies can optimize allocations from prices, covariances, and prior positions, yet they lack a calibrated, replayable mechanism for certifying that a proposed allocation respects a bounded risk envelope before execution. Regulators increasingly expect automated portfolio systems to provide exactly this kind of pre-trade audit trail, interpretable risk limit, and human-oversight mechanism. Gated Conformal Semantic Risk Control addresses this gap by separating return-seeking allocation from text-conditioned downside-risk verification. An instruction-tuned language model maps timestamped disclosures into schema-validated semantic risk states over macro, liquidity, earnings, and sector channels. These states induce correlated ellipsoidal factor-shock uncertainty sets whose conformal radii are calibrated by rolling finite-sample prediction over localized semantic nonconformity buckets. An asymmetric second-order cone gate then checks each raw PPO proposal against a certified worst-case semantic loss budget. The gate stays inactive for compliant proposals and intervenes only when that budget is exceeded. In walk-forward out-of-sample tests on nine liquid U.S. Select Sector SPDR ETFs, Raw PPO earns a 12.7% annual return while incurring a 4.05% semantic violation rate. Gated-CSRC removes all observed out-of-sample semantic limit breaches while retaining an 11.7% annual return. This 100-basis-point auditable safety premium is smaller than the yield loss imposed by unconditional hard projection, and exact McNemar testing confirms the compliance gain at $p < 10^{-15}$. Loughran-McDonald lexicon controls and time-shuffled text controls fail to reproduce this certificate.
