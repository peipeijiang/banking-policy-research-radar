# 违约概率建模中信用行为的函数表示

<summary><strong>中文摘要</strong></summary>

本文提出了一种通过函数型数据分析（functional data analysis）对违约概率进行建模的框架。通过将一系列信用变量表示为函数，我们研究了月内信息是否能提高线性模型中违约预测能力。我们进一步展示了如何从随时间观测到的三个量中推导出一系列广泛使用的变量，其中包括可用资金、使用率和透支额度。这三个量分别是：1）每个账户的类型，2）账户余额，3）账户信用额度的大小。将这些量保留为连续时间过程，而非将其简化为月度汇总值，可以得到对借款人的连续忠实表示。在分析这三个过程时，我们发现与银行工作日序数位置相关的重复事件产生了强烈的周期性模式。因此，我们开发了一个相对时间框架，使不同借款人的重复事件对齐，确保借款人无论实际时间如何都具有相同的周期性模式。我们使用函数型逻辑回归（functional logistic regression）对该框架进行评估。该方法既适应连续表示，又与信用风险实践中因严格监管约束而常用的逻辑回归模型保持密切关联。我们表明，当配备有效的交易轨迹函数型表示时，所提出的模型在预测性能上达到了与XGBoost相当的水平，同时持续优于逻辑回归。重要的是，该模型在机器学习模型的预测性能与线性违约模型的可解释性之间取得了平衡，有望使金融机构即使在严格监管下也能使用该模型。

<summary><strong>英文摘要</strong></summary>

This paper proposes a framework for modeling probability of default via functional data analysis. By representing a series of credit variables as functions, we investigate whether intra-monthly information improves default predictability in linear models. We further show how a range of widely used variables, among them available funds, utilization rate, and overdraft, can all be derived from three quantities observed over time. Namely, 1) the type of each account, 2) the balance of the account, and 3) the size of the credit limit on the account. Retaining these quantities as continuous-time processes, rather than reducing them to monthly aggregated values, yields a continuous faithful representation of the borrower. When analyzing these three processes, we discovered that recurring events associated with the ordinal position among banking days created strong cyclical patterns. We therefore develop a relative time framework that aligns the recurring events across borrowers, ensuring that borrowers possess the same cyclical pattern, regardless of real time. We assess the framework using functional logistic regression. This approach accommodates the continuous representation while remaining closely related to a logistic regression model commonly used in credit risk practice, due to strict regulatory constraints. We show that, when equipped with an effective functional representation of transactional trajectories, the proposed model attains predictive performance on par with XGBoost while consistently outperforming logistic regression. Importantly, the model balances predictive performance of a machine learning model with the interpretability of linear default models, potentially enabling financial institutions to use the model, even under strict regulation.

## 深度解读

> 分析依据：**全文深读**

### 核心结论

本文提出一个基于函数型数据分析（FDA）的违约概率（PD）建模框架。作者指出，传统PD模型通常将交易历史聚合为月度或季度汇总变量，丢弃了月内动态信息。论文证明，可用三个连续时间过程（账户类型、账户余额、信用额度）构建常见的信用行为变量（可用资金、利用率、透支、杠杆率、相对透支）。通过将观测限制在银行日，作者发现余额路径存在与月内序数位置相关的强周期性（月末工资入账、月初固定支出）。为此，论文构建相对时间网格对齐不同借款人的周期性事件，并采用函数型逻辑回归进行建模。实证结果表明，该函数模型在AUC等损失指标上显著优于标准逻辑回归，并与XGBoost基准性能相当，同时保持线性模型的可解释性。

### 主要创新

- 首次将函数型数据分析与月内（银行日）观测相结合来建模借款人违约，保留日度信息及其时间结构。
- 提出用三个连续时间过程（账户类型、余额、信用额度）统一表示信用行为变量，而非预先固定一组月末汇总特征。
- 发现并利用银行日序数位置导致的强周期性模式，构建相对时间网格对齐不同借款人的重复事件。
- 采用函数型逻辑回归，在保持线性模型可解释性和监管合规性的同时，获得与XGBoost相当的预测性能。

### 研究方法

论文将每个借款人的信用行为变量视为连续时间过程，在银行日末进行观测。使用三次B样条基和均值样条基对轨迹进行函数化表示，通过惩罚最小二乘法估计样条系数。采用函数型逻辑回归，将线性预测子表示为积分形式，通过基展开将问题转化为普通逻辑回归，并使用粗糙度惩罚和REML选择平滑参数。为处理月内银行日数量不等的问题，构建相对时间网格，将每月最后一个银行日映射到固定坐标。变量选择采用基于验证集AUC的贪心前向选择。

### 关键结果

函数型逻辑回归在AUC等损失指标上显著优于标准逻辑回归，并与XGBoost基准性能相当。；最终选入函数模型的变量为：家庭杠杆率（M=9，三次样条，λX=0.0001）、借款人相对透支（M=12，均值样条，λX=0）、家庭可用资金（M=3，三次样条，λX=1），所有p值均小于0.001。；标准逻辑回归选入的变量为：家庭可用资金（M=0）、家庭杠杆率（M=6）、借款人相对透支（M=12），所有p值均小于0.001。；估计的系数函数与信用直觉一致：更高的杠杆率和更大的透支对应更高的违约风险。；余额路径呈现明显的月内周期性：月末最后一个银行日工资入账导致余额跳升，次月第一个银行日固定支出导致余额骤降。

### 技术栈

- 函数型数据分析（FDA）
- 函数型逻辑回归
- B样条基（Cox–de Boor递归）
- 惩罚最小二乘法
- 粗糙度惩罚
- 限制最大似然（REML）
- 惩罚迭代重加权最小二乘法
- 相对时间网格对齐
- 贪心前向变量选择
- AUC评估
- Bootstrap置信带
- XGBoost基准
- 标准逻辑回归

### 方法优势

- 保留了日度交易信息及其时间结构，避免了月度聚合造成的信息损失。
- 提出的三过程表示框架具有通用性，可推广至其他信用风险应用。
- 函数型逻辑回归属于线性模型类别，具有可解释性和监管合规潜力。
- 相对时间对齐方法有效解决了不同借款人月内银行日数量不等的问题。
- 实证结果同时包含样本内和样本外时间测试，增强了结论的稳健性。

### 主要局限

- 论文仅关注PD建模，未探索该表示框架在行为监控等其他信用风险领域的应用。
- 函数型逻辑回归中β函数仅使用5个基函数，可能限制模型灵活性。
- 变量选择基于验证集AUC的贪心前向选择，未采用交叉验证，作者虽提及测试后无变化，但未展示详细结果。
- 数据仅来自丹麦一家金融机构（Nykredit），外部有效性有待验证。
- 论文未提供具体的AUC数值或损失指标数值，仅以文字描述性能对比。

### 与当前研究方向的关联

本文与银行信贷与风险承担、信用周期、金融稳定等关键词高度相关。论文直接研究零售借款人违约概率建模，属于银行信贷风险管理的核心内容。通过函数型数据分析捕捉月内信用行为动态，有助于更及时地识别借款人财务状况恶化，对金融稳定和信用周期监测具有潜在政策含义。同时，模型在保持线性可解释性的前提下达到机器学习预测性能，对监管合规下的风险建模实践具有参考价值。
