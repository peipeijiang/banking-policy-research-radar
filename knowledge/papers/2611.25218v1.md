<summary><strong>中文摘要</strong></summary>

机器转录与人工双录入数据的一致性有多高？我们对1912年和1921年版的《美国医学名录》（American Medical Directory，AMD）进行了数字化处理。该名录是美国医师的全国性登记册，两卷分别收录约14万和15万条记录。我们将五种机器提取工作流程与全量计数的双录入人工转录进行了比较。与许多历史名录一样，AMD是半结构化的而非表格化的，因此错误不仅来自文本误读，也来自版面布局的误判。一个使用编码代理编写的规则来解析商业OCR文本的脚本，能够恢复约97%的人工转录记录，且精确率相当，优于读取页面图像和OCR文本的多模态语言模型工作流程（gemini-2.0.flash）。当两种方法失败时，它们失败的记录集部分重叠，因此对二者输出进行协调可将召回率和精确率均提升至约98%。在本地GPU服务器上运行的开源权重LLM流水线，其召回率介于解析器脚本和多模态工作流程之间；将商业OCR模型替换为开源替代方案仅使其召回率降低约2个百分点。由于人工转录自身的错误率未知，这些比率衡量的是 agreement（一致性）而非 accuracy（准确性）。商业OCR和多模态工作流程的直接处理费用约为每页0.03欧元，而人工转录为每页14.70欧元。

<summary><strong>英文摘要</strong></summary>

How closely does machine transcription agree with manual double-entry data? We digitize the 1912 and 1921 editions of the American Medical Directory, a national register of US physicians with roughly 140,000 and 150,000 entries in the two volumes, and compare five machine-extraction workflows with a full-count double-entered manual transcription. Like many historical directories, the AMD is semi-structured rather than tabular, so errors arise from misreading the layout as well as the text. A script that parses commercial OCR text using rules written by coding agents recovers about 97 percent of manually transcribed records with similar precision, more than a multimodal language model workflow (gemini-2.0.flash) that reads the page images and the OCR text. When the two methods fail, they fail on partly overlapping sets of records, so reconciling their outputs raises both recall and precision to about 98 percent. An open-weight LLM pipeline run on a local GPU server falls between the parser and the multimodal workflow in recall, and replacing the commercial OCR model with an open-source alternative lowers its recall by only about 2 percentage points. As the manual transcription's own error rate is unknown, these rates measure agreement rather than accuracy. Direct processing charges for the commercial OCR and multimodal workflow were about 0.03 euro per page, compared with 14.70 euro per page for manual transcription.
