<summary><strong>中文摘要</strong></summary>

我们研究Balbuzanov和Kotowski（2019）针对具有复杂禀赋的物体分配问题所提出的排斥核心（exclusion core）。我们关注混合所有权物体分配问题，其中每个物体要么由某个代理人个人所有，要么由所有代理人共同公有。给定代理人之间的优先顺序、禀赋结构、初始分配以及代理人偏好，我们构建连续最高交易循环（serial top trading cycles, STTC）图，并定义相关的STTC算法。该算法是我们分析排斥核心稳定分配的核心工具。

首先，我们表明，在由禀赋结构限制所定义的各领域中，混合所有权领域是STTC算法能够刻画排斥核心的最大领域。其次，我们为排斥核心稳定性提供了一个简单检验：一个分配是排斥核心稳定的，当且仅当它是从该分配出发初始化的STTC算法的一个不动点，且与优先顺序无关。第三，我们表明排斥核心在排斥支配（exclusion-domination）意义下是一个von Neumann--Morgenstern（1944）稳定集。最后，我们研究一个动态排斥阻阻过程，并表明从任意分配出发，都存在一条自包含的排斥阻阻路径通向排斥核心。

<summary><strong>英文摘要</strong></summary>

We study Balbuzanov and Kotowski's (2019) exclusion core for object allocation problems with complex endowments. We focus on mixed-ownership object allocation problems in which each object is either individually owned by one agent or publicly owned by all agents. Given a priority order over agents, an endowment structure, an initial allocation, and agents' preferences, we construct serial top trading cycles (STTC) graphs and define the associated STTC algorithm. The algorithm is the central tool for our analysis of exclusion-core-stable allocations.
  First, we show that, among domains defined by restrictions on endowment structures, the mixed-ownership domain is the largest on which the STTC algorithms characterize the exclusion core. Second, we provide a simple test for exclusion core stability: an allocation is exclusion core stable if and only if it is a fixed point of the STTC algorithm initialized at that allocation, independently of the priority order. Third, we show that the exclusion core is a von Neumann--Morgenstern (1944) stable set with respect to exclusion-domination. Finally, we study a dynamic exclusion-blocking process and show that, from any allocation, there exists a self-contained exclusion-blocking path to the exclusion core.
