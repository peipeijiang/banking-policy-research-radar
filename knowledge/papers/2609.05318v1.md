<summary><strong>中文摘要</strong></summary>

基于Kearns、Roth和Ryu（SODA'26）的开创性论文，我们研究了网络化学习模型中的信息聚合问题。该模型捕捉了智能体人工智能（agentic AI）中的一个核心模式：每个智能体仅看到部分数据，并且只传递其自身的结论。他们的模型考虑了一个采用均方误差（MSE）损失的线性回归问题。智能体位于一个有向无环图（DAG）中，每个智能体仅看到特征的一个子集及其父节点的预测，拟合一个线性预测器，并且仅将其预测向前传递。基准是全特征学习器，它能看到所有原始特征。一条深度为$D$的路径被称为$M$-覆盖的，如果每$M$个连续智能体组成的块共同看到了所有原始特征。Kearns、Roth和Ryu证明了在这样的路径上，最后一个智能体的超额均方误差为$O(M/\sqrt D)$，并给出了一个循环实例，其超额误差在$D<M^2$时为$Ω(M/D)$。

我们弥合了这一差距：正确的速率在深度达到$M^2$之前是常数，而在其之后为$Θ(M^2/D)$。我们首先对循环实例进行了更精细的分析，并将其下界改进为$D<M^2$时的$Ω(\sqrt{M/D})$。然后，我们为每个深度$D\ge M^2$构造了一条深度为$D$的$M$-覆盖路径，其超额误差为$Ω(M^2/D)$。同一个实例也为所有$D < M^2$提供了常数下界。我们还表明，对于任何固定分布，超额误差沿路径呈几何级数收缩，这排除了任何单个实例在所有深度上见证任何多项式下界的可能性。

最后，我们在Bateni等人的logit传递模型中证明了逻辑分类的相同最优速率，该模型考虑二元交叉熵（BCE）损失。改进后的上界$O(M^2/D)$仍然成立，并且我们通过证明在这些实例上逻辑路径在重缩放后遵循最小二乘路径，将所有回归下界进行了转移。

<summary><strong>英文摘要</strong></summary>

Building on the pioneering paper of Kearns, Roth, and Ryu (SODA'26), we study information aggregation in a networked learning model. The model captures a central pattern in agentic AI: each agent sees only part of the data and passes on only its own conclusion. Their model considers a linear regression problem with the mean squared error (MSE) loss. Agents sit in a DAG and each sees only a subset of the features and its parents' predictions, fits a linear predictor, and passes only its prediction forward. The benchmark is the full-feature learner that sees all raw features. A path of depth $D$ is $M$-covered if every block of $M$ consecutive agents collectively sees all raw features. Kearns, Roth, and Ryu proved that the excess mean squared error of the last agent on such a path is $O(M/\sqrt D)$, and gave a cyclic instance with excess error $Ω(M/D)$ for $D<M^2$.
  We close this gap: the correct rate is constant up to depth $M^2$, and $Θ(M^2/D)$ beyond it. We first give a sharper analysis of the cyclic instance and improve its lower bound to $Ω(\sqrt{M/D})$ for $D<M^2$. We then construct, for every depth $D\ge M^2$, an $M$-covered path of depth $D$ with excess error $Ω(M^2/D)$. The same instance gives the constant lower bound for all $D < M^2$. We also show that for any fixed distribution the excess error contracts geometrically along the path, ruling out any single instance that witnesses any polynomial lower bound at every depth.
  Finally, we prove the same optimal rate for logistic classification in the logit-passing model of Bateni et al., which considers the binary cross-entropy (BCE) loss. The same improved upper bound of $O(M^2/D)$ holds, and we transfer all the regression lower bounds by showing that on those examples the logistic path follows the least-squares path up to rescaling.
