<summary><strong>中文摘要</strong></summary>

信息矩阵（Information Matrix, IM）检验是基于似然模型的自然设定检验，然而横截面情形下的实现往往存在严重的检验水平扭曲，将忽略的异质性与分布误设定相混淆，并且需要三阶导数。我们针对含固定效应的模型发展了面板信息矩阵（Panel Information Matrix, PIM）检验。显式固定效应将函数形式误设定与时不变未观测异质性隔离开来。尽管轮廓最大似然估计量继承了$O(1/T)$阶的附带参数偏差，但轮廓PIM的主导偏差为$\sqrt{n}/T$阶，因此当$n/T^2\to 0$时该偏差渐近可忽略，这一条件涵盖矩形渐近情形$n/T\to\mathrm{const}$，并在抛物渐近$n/T^2\toρ\in(0,\infty)$下保持稳定。这种稳健性源于指示函数以$\sqrt{n}$而非$\sqrt{nT}$的速率波动。相同的速率论证使得三阶导数修正在渐近意义上不再必要，因此该检验仅使用一阶和二阶似然导数。模拟结果证实，在中等长度的面板中，渐近PIM临界值已经足够，即使对$θ$的Wald检验存在严重的水平扭曲；而当$ρ>0$时，参数自助法在很大程度上消除了水平扭曲。

<summary><strong>英文摘要</strong></summary>

The Information Matrix (IM) test is a natural specification check for likelihood-based models, yet cross-sectional implementations are often badly sized, confound neglected heterogeneity with distributional misspecification, and require third derivatives. We develop the panel information matrix (PIM) test for models with fixed effects. Explicit fixed effects isolate functional-form misspecification from time-invariant unobserved heterogeneity. Although the profile maximum likelihood estimator inherits incidental-parameter bias of order $O(1/T)$, the leading bias of the profile PIM is of order $\sqrt{n}/T$, so it is asymptotically negligible whenever $n/T^2\to 0$, which includes the rectangular regime $n/T\to\mathrm{const}$, and stabilizes under parabolic asymptotics $n/T^2\toρ\in(0,\infty)$. This robustness arises because the indicator fluctuates at rate $\sqrt{n}$ rather than $\sqrt{nT}$. The same rate argument makes third-derivative corrections asymptotically unnecessary, so the test uses only first- and second-order likelihood derivatives. Simulations confirm that asymptotic PIM critical values suffice in moderately long panels, even when Wald tests for $θ$ are badly sized, while a parametric bootstrap largely removes size distortions when $ρ>0$.
