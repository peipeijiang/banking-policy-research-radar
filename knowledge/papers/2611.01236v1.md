<summary><strong>中文摘要</strong></summary>

稳健的金融风险推断不仅需要数学上的正确性。模型必须准确应用条件规则、维护不断演化的金融状态，并做出尊重运营约束的决策。本研究提出RiskReason，一个用于可验证金融风险推理的基准，涵盖多样化的风险管理机制。该基准包括Standard任务（评估单个金融机制）和Long-horizon任务（通过扩展依赖关系组合多个机制）。每个任务提供参考结果、形式化规范、推理标注和依赖表示，以支持对模型性能的系统分析。采用严格的单次尝试准确率评估了十一种模型配置，并辅以结构性和定性失败分析。最强的配置达到80.0--90.2%的总体准确率，其中若干配置在组合金融场景上保持高性能。然而，对失败案例的分析揭示了以下问题：中间计算准确但风险决策错误、金融状态传播不一致，以及补救措施违反约束性限制。相比之下，一些严格评估中的失败源于报告不完整，而非金融结论错误。这些发现表明，仅凭总体准确率不足以刻画金融风险推理的可靠性，并推动了对能够区分数值正确性、状态一致性、约束满足和决策有效性的评估的需求。

<summary><strong>英文摘要</strong></summary>

Robust financial-risk inference requires more than mathematical correctness. Models must accurately apply conditional rules, maintain evolving financial states, and make decisions that respect operational constraints. This work introduces RiskReason, a benchmark for verifiable financial-risk reasoning that spans diverse risk-management mechanisms. The benchmark includes Standard tasks, which assess individual financial mechanisms, and Long-horizon tasks, which combine multiple mechanisms through extended dependencies. Each task provides reference outcomes, formal specifications, reasoning annotations, and dependency representations to support systematic analysis of model performance. Eleven model configurations are evaluated using strict single-attempt accuracy, complemented by structural and qualitative failure analyses. The strongest configurations achieve 80.0--90.2\% overall accuracy, with several maintaining high performance on composed financial scenarios. However, analysis of failures reveals incorrect risk decisions despite accurate intermediate calculations, inconsistent propagation of financial states, and remediation actions that violate binding constraints. In contrast, some strict evaluation failures result from incomplete reporting rather than incorrect financial conclusions. These findings indicate that aggregate accuracy alone is insufficient to characterize financial-risk reasoning reliability and motivate evaluations that distinguish numerical correctness, state consistency, constraint satisfaction, and decision validity.
