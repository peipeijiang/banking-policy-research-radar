<summary><strong>中文摘要</strong></summary>

在本文中，我们研究受限异质性（restricted heterogeneity）模型。随机效用模型（random utility model）允许理性类型之间存在任意异质性，而我们考虑分析者事先将理性类型集合限制为某个较小的允许类型集合的情形。我们研究这种形式限制的行为内容、模型拟合以及识别性质。我们发现，这三者都可以通过一个由可观测数据构造的共同价值函数（value function）联系起来。与受限异质性模型的一致性由该价值函数取值为1来刻画，而模型拟合则由一个可能小于1的取值给出。给定受限异质性模型的部分识别集（partially identified set）通过该价值函数的次微分（subdifferential）来刻画。

<summary><strong>英文摘要</strong></summary>

In this paper, we study models of restricted heterogeneity. While the random utility model allows for arbitrary heterogeneity among rational types, we consider the case when an analyst ex-ante restricts the set of rational types to some smaller set of allowable types. We study the behavioral content, the model fit, and the identification properties of restrictions of this form. We find that all three of these can be connected through a common value function that is constructed from observable data. Consistency with a model of restricted heterogeneity is characterized by this value function achieving a value of one, while model fit is given by a value that is potentially less than one. The partially identified set for a given model of restricted heterogeneity is characterized by way of the subdifferential of this value function.
