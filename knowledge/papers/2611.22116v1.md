<summary><strong>中文摘要</strong></summary>

保留制度的研究主要考虑静态情形，即针对给定的分配问题制定并研究选择规则。动态情形的不同之处在于问题并非事先给定。随着时间推移，更多职位变得可用，而每次机构都必须根据过去的情况构建当前问题。我们区分了台账（ledger）、账户（account）和选择规则（choice rule）：台账存储关于先前分配的信息，账户将这些数据转化为当前问题，选择规则则为该问题选择一个结果。同一选择规则在不同账户下可以实施截然不同的政策。如果每批新人员被分配时保持先前接受者及其类别不变，那么随着批次缩小，我们所研究的最慷慨的保留政策——额外保留（over-and-above）——可能选出与最保守的最低保障（minimum guarantee）几乎相同的接受者。累积实施（cumulative implementation）使用不同的账户，重新考虑先前接受者的类别，从而防止这种压缩。我们通过资源释放不变性（resource-release invariance）来刻画它。在出现新到达者或优先级变化时，普通选择规则可能会拒绝一位其任命必须被履行的先前接受者。我们引入并刻画了保留、重新分配和提升（retain, reassign, and boost, RRB）选择规则，在该规则下每位在任者保留其任命且其类别可以被更改。将RRB与个人提议延迟接受（individual-proposing deferred acceptance）相结合，得到一种策略防伪机制，在该机制下每位在任者要么保留其任命，要么获得一个其更偏好的任命。应用包括学校和大学招生中的等待名单、公开招聘以及法院命令的纠正措施。

<summary><strong>英文摘要</strong></summary>

Research on reserve systems mainly considers static settings, formulating and studying choice rules for a given allocation problem. Dynamic settings are different in that the problem is not given. Over time, more positions become available, and each time the institution must build the current problem from its past. We distinguish the ledger, which stores information about earlier allocations, the account, which transforms these data into the current problem, and the choice rule, which selects an outcome for that problem. The same choice rule can implement very different policies under different accounts. If each new batch is assigned while holding earlier recipients and their categories fixed, then as batches shrink, over-and-above, the most generous reserve policy we study, can select nearly the same recipients as minimum guarantee, the most conservative one. Cumulative implementation uses a different account, which reconsiders the categories of earlier recipients, and prevents this compression. We characterize it by resource-release invariance. With arrivals or changes in priorities, the ordinary choice rule might reject an earlier recipient whose appointment has to be honored. We introduce and characterize retain, reassign, and boost (RRB) choice rules, under which every incumbent retains her appointment and can have her category changed. Combining RRB with individual-proposing deferred acceptance gives a strategy-proof mechanism under which each incumbent keeps her appointment or receives one she prefers. Applications include waiting lists in school and university admissions, public recruitment, and court-ordered corrections.
