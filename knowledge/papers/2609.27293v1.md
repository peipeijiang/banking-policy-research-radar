<summary><strong>中文摘要</strong></summary>

匹配机制之间的差异在于，为了获得某一特定对象，代理人偏好排序需要被确定和报告的程度不同。如果一个代理人通过某种报告所能获得的每一个对象，也可以通过仅报告该对象为可接受对象来获得，则该机制具有单元素可达性（singleton-attainable, SA）。在SA机制下，一旦一个可达对象被识别出来，代理人就无需对任何其他对象进行排序或报告。单元素可达性识别了匹配理论与市场设计中的一个独特维度：对可达结果的透明获取，这有别于激励、稳定性、福利或公平。

我们建立了SA的一般条件并推导了其策略含义。最高提升不变性（top-lift invariance）与截断不变性（truncation invariance）共同蕴含SA，而策略防篡改性和稳定性各自蕴含SA。相比之下，任何对策略防篡改、个体理性且非浪费机制的帕累托改进都不具有SA。特别地，对延迟接受机制（Deferred Acceptance）的每一个帕累托改进都违反SA。我们引入了报告宽度（report width），用以衡量为获得某一对象可能需要报告多少个可接受对象。SA机制的报告宽度为一。

对于一大类对延迟接受机制进行帕累托改进的有效机制而言，报告宽度是无界的。当优先级单调时，具有报告诱导优先级的稳定选择其宽度为一，而在反向优先级支配下具有最大宽度。当外部选项排名固定时，排名福利最大化（rank-welfare maximization）的宽度为一，而当其依赖于报告时则具有最大宽度。这些结果揭示了一种结构性分野，我们将其称为宽度二分法（width dichotomy）：在我们的分类中的所有机制和族以及我们所研究的所有结构类别中，报告宽度要么为一，要么无界。

<summary><strong>英文摘要</strong></summary>

Matching mechanisms differ in how much of an agent's preference ranking must be determined and reported to obtain a particular object. A mechanism is singleton-attainable (SA) if every object that an agent can obtain through some report can also be obtained by reporting only that object as acceptable. With an SA mechanism, once an attainable object has been identified, the agent need not rank or report any other object. Singleton-attainability identifies a distinct dimension in matching theory and market design: transparent access to attainable outcomes, separate from incentives, stability, welfare or equity.
  We establish general conditions for SA and derive its strategic implications. Top-lift invariance and truncation invariance together imply SA, while strategyproofness and stability each imply SA. By contrast, no Pareto improvement over a strategyproof, individually rational, and non-wasteful mechanism is SA. In particular, every Pareto improvement over Deferred Acceptance violates SA. We introduce report width, which measures how many acceptable objects may have to be reported to obtain an object. SA mechanisms have report width one.
  Report width is unbounded for a large class of efficient mechanisms that Pareto-improve Deferred Acceptance. Stable selection with report-induced priorities has width one when priorities are monotone and maximal width under reverse priority dominance. Rank-welfare maximization has width one when the outside-option rank is fixed and maximal width when it is report-dependent. These results reveal a structural divide, which we call the width dichotomy: across all mechanisms and families in our classification and all structural classes we study, report width is either one or unbounded.
